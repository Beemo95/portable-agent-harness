## Reproduction / honest readiness

The staging revision `04b8d78` passed [GitHub Actions CI](https://github.com/Beemo95/portable-agent-harness/actions/runs/44511050376), including script syntax, documentation/STATUS checks and positive/negative regression fixtures. Subsequent documentation-only changes require their own final CI. The CI is not a standalone validator of user intent, product quality, OS compatibility or current official-page meaning.

For a real project, first use [adoption](adopting-existing-project.md) and replace template STATUS with observed code/version/revision. Then follow [actual-agent evaluation](evaluation.md): check each tool's instruction/Skill discovery, inspect code first, phase planning, test gates, historical knowledge recovery, and cross-model handoff. Log commands, versions, revisions and evidence; report any missing tools as NOT RUN. Do not claim pass solely from this report.

## Risks not resolved by Markdown checks

- Actual test coverage, acceptance semantics, stale factual claims and model interpretation remain unverified until agents and real Godot source are exercised.
- The GitHub Actions source-review deadline alerts only for dated metadata, not upstream content changes before the deadline.
- User/organization/parent-directory instructions, plugins and global Skills can take precedence or collide at runtime. Validate loaded sources per installed agent.
- OpenSpec and Godot minor versions may evolve; official version-specific documentation and actual installed commands remain authoritative at the time of use.
- Concurrent Git worktrees, ignored binaries and unpushed changes are not automatically preserved by Markdown/Git protocols.
