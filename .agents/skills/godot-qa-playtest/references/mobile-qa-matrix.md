# Mobile QA scenarios (check applicable cases only)

| Area | Examples of actual checks |
| --- | --- |
| Input | touch drag/tap accuracy, gestures, simultaneous touches, paused/resumed input |
| Layout | portrait/landscape, cutouts/safe area, small and wide aspect ratios, text overflow |
| Gameplay | onboarding, save/load, stage reset, failure/retry, transitions, difficulty boundaries |
| Visuals | filtering, z-order, clipping, sprite frame mismatch, motion direction, sound/VFX synchronization |
| Performance | actual device FPS/memory/thermal behavior, asset load time, stutter reports |
| Android export | version/preset/signing, startup/crash logging, permission/age disclosures when required |

For each scenario record test environment, PASS/FAIL/NOT RUN, reproduction and evidence links. `--headless` is not a substitute for device observation.
