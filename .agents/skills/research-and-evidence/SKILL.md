# Evidence-led research

1. Read `.agent-docs/rules/research.md` and scope question/version/platform. Read provided source material before third-party summaries.
2. Prefer official Godot docs and direct upstream repository/release/license files; confirm URL contents, release and dates.
3. Compare trade-offs if necessary, including license, import complexity, portability and maintenance; distinguish tested from assumed.
4. Record reusable findings in `.agent-docs/research/YYYY-MM-DD-topic.md` with links, evidence, unknowns and recommendation.
5. Return a concise summary + direct sources to the requesting agent; do not fill the main context with unfiltered search results.
