# Preserve project work

1. Read `ai-docs/rules/documentation.md`, the linked OpenSpec change, current project STATUS and actual Git diff.
2. Reconcile completed/unfinished work; update OpenSpec checkboxes only for implemented items. Separate tested, visually reviewed and device-verified claims.
3. Record only meaningful new decisions or research. Update `ai-docs/project/STATUS.md` with blockers and one concrete next step.
4. Use `ai-docs/templates/handoff.md` for substantial handoff; include files, exact commands/evidence, known risks, branch and actual commit/push status.
5. Never promise that local uncommitted work, ignored assets, secrets or external services will travel with a Git clone.
