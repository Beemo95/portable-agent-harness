# Pixel + isometric art checklist

- Desired output is **image sprite**, **vector**, or **code-generated**? Produce the requested type.
- Correct scale, PPU, filtering, viewport stretch and pixel-snap policy established.
- Sprite animation frame count/order, direction axes, left/right limbs and loop continuity checked in running preview.
- Tile footprint, isometric projection, origin, pivot, z-index/y-sort/depth mask, collision tested with overlapping moving objects.
- Source assets editable; file provenance and license recorded if externally sourced.
- Real screenshot or GIF captured from running Godot when possible; simulated drawings are not runtime proof.
