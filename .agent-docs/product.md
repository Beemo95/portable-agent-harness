# Product intent

## Goal
A portable project harness enabling an otherwise fresh AI agent to discover relevant context, execute safe work, verify results and resume tasks across sessions, models and computers.

## Non-goals (v1)
- Hosting models or providing a multi-agent chat UI.
- Perfect reproduction of hidden model state or proprietary session caches.
- Automatic secret/authentication transfer.
- Automatic installation of arbitrary OS packages or execution of untrusted project commands without user review.

## Intended users
Individual developers and small cross-functional AI teams, with project-specific workflows.
